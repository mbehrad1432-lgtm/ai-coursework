# Artificial Intelligence Coursework

Practical AI assignments by **Behrad Mazaheri**, completed for the Artificial Intelligence course at **Sharif University of Technology, Spring 2025**.

This repository presents implemented algorithms, reproducible experiments and explanations of their behavior. Each assignment includes attribution to the supplied course material and notes on revisions made for this portfolio edition.

| Assignment | Topics | Materials |
| --- | --- | --- |
| [HW01: Search and Optimization](hw01-search-and-optimization/) | DFS, BFS, A*, stochastic hill climbing, genetic algorithms, TSP | Executed notebook, 51-city data, experiment results, verification scripts |

| [HW02: Adversarial Search, MDP and RL](hw02-adversarial-search-mdp-rl/) | Minimax, Alpha-Beta, Value Iteration, Q-learning, Monte Carlo evaluation | Executed notebook, reusable algorithms, correctness checks, seeded results |

| [HW03: Probabilistic Models and Particle Filtering](hw03-probabilistic-models-particle-filter/) | Bayesian networks, exact inference, sampling, robot localization | Executed notebook, headless maze, 16 correctness checks, seeded results |

| [HW05.1: Classical ML from Scratch](hw05-1-classical-ml/) | Linear/logistic regression, Gini decision tree | Executed notebook, NumPy implementations, held-out metrics, 16 correctness checks |

| [HW05.2: NumPy MLP](hw05-2-numpy-mlp/) | Backpropagation, MSE/L2, SGD momentum, housing regression | Executed notebook, bundled data, 25 checks, checkpoint and held-out metrics |

**Stack:** Python, NumPy, Matplotlib, Gymnasium, pgmpy, Jupyter notebooks.

Start with the [assignment guide](hw01-search-and-optimization/README.md) for setup, results and limitations.
